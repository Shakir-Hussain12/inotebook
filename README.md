# 📖 [iNoteBook] <a name="about-project"></a>

> iNoteBook, as the name suggests is an online web application that allows you to store & manage your personal notes, and keeps the data secured through the use of JWT tokens.

## 💻 Getting Started <a name="getting-started"></a>

> To get a local copy up and running, follow these steps.

### Prerequisites

In order to run this project you need:
- node
- npm
- VSCode or other IDE
- GitHub
- Git

### Setup

Clone this repository to your desired folder:

> git clone git@github.com:Shakir-Hussain12/inotebook.git

### Install

Install this project with:
- npm install

### Usage

> To run the project, execute the following command:
- npm start

> To run Server Side, execute the following commands:
- cd backend
- npm start

### Run tests

> To run tests, run the following command:

- npm run test

**For E2E tests, run the following command**
- npm run cy

  It will open cypress UI & you can use it to run the tests manually
